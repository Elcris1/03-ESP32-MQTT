# 03-ESP32-FreeRTOS
## Dev
Dev configuration can be done using wokwi and platform io. Use [platoformio.ini](dev.platformio.ini) to configure alongise [wokwi](wokwi.toml)
```bash
cp dev.platformio.ini platformio.ini
```
After this you can build the project sucessfully

## Real
IRL configuration can be done adapting the used platformio configuration. Use [platoformio.ini](real.platformio.ini).
```bash
cp real.platformio.ini platformio.ini
```
After this you can build the project sucessfully
